# Cooler Hello World

Um programinha em Java que escreve o famoso "Hello World!" de uma forma diferente: descobrindo a frase letra por letra, como se estivesse "quebrando um código".

## Como funciona

O programa testa, posição por posição, todas as letras do alfabeto até encontrar a letra correta da frase "Hello World!". Cada vez que acerta uma letra, ela é fixada e o programa segue para a próxima posição, com um pequeno delay entre as tentativas — dando a impressão de que o texto está sendo "descoberto" aos poucos no terminal.

## Tecnologias

- Java (sem bibliotecas externas)

## Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/guparaiso/cooler-hello-world.git
```
2. Entre na pasta do projeto e compile:
```bash
   javac src/Main.java
```
3. Execute:
```bash
   java -cp src Main
```
